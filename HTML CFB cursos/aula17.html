Tag canvas - Curso de HTML Completo e Profissional #17

🧩 Tag canvas (Área de Desenho Gráfica) Função principal: A tag canvas cria uma área retangular em que é possível desenhar gráficos, imagens, animações ou jogos usando JavaScript. Sozinha, a tag não exibe nada — ela serve apenas como um espaço de desenho programável.

Seu navegador não suporta o elemento canvas.
