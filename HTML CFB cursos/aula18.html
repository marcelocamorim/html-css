🧩 Tag <code>(Trecho de Código)

Função principal: A tag é usada para exibir trechos de código (HTML, JavaScript, Python, etc.) dentro de um texto. Ela aplica uma fonte monoespaçada (como em editores de código) e indica que aquele conteúdo é código legível por humanos.

Use a tag <h1> para criar um título principal.
