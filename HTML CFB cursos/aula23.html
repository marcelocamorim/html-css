🧩 Tag <div> (Divisão ou Seção Genérica)

Função principal:

A tag <div> é usada para agrupar elementos HTML em blocos, permitindo organizar o layout e aplicar estilos ou scripts a partes específicas de uma página. Ela não tem significado semântico — serve apenas como um contêiner genérico.
