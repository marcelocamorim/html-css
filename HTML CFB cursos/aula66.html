✔️ ruby — Anotação de texto (principalmente idiomas asiáticos)

A tag ruby serve para exibir anotações de pronúncia sobre um texto. Muito usada em japonês, chinês e outras línguas que utilizam caracteres complexos. Essa anotação é chamada de furigana (no japonês) ou ruby text.

✔️ rt — Ruby Text (pronúncia)

A tag rt é usada dentro de ruby para indicar como o texto deve ser lido.

✔️ Exemplo básico

漢 kan 字 ji

Isso mostra os caracteres com a pronúncia logo acima.
