Tags blockquote e cite, trabalhando com citações - Curso de HTML Completo e Profissional #14

tag blockquote

Resumo: A tag é usada para exibir citações longas ou trechos de texto retirados de outra fonte. Normalmente, os navegadores mostram o texto com recuo e espaçamento diferenciado, indicando visualmente que é uma citação.

tag cite

Resumo: A tag é usada para indicar o nome de uma fonte, obra, livro, filme, artigo, autor ou site de onde a citação foi tirada. O navegador geralmente exibe o texto em itálico.
