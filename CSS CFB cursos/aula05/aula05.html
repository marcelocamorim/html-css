Curso de CSS3 #05 - background - Parte 2 - background-clip, padding, border

border-box Aqui, o valor de width e height inclui o conteúdo + padding + border. Ou seja, o tamanho total nunca passa dos valores definidos.

CFB Cursos

padding-box É menos usado. Nesse modo, a largura e altura incluem o conteúdo + o padding, mas não incluem a borda.

CFB Cursos

content-box (padrão) É o comportamento padrão do CSS. Quando você define width e height, elas valem apenas para o conteúdo — o padding e a border são adicionados por fora, aumentando o tamanho total do elemento.

CFB Cursos

Dica profissional A maioria dos desenvolvedores define border-box para todos os elementos logo no início do CSS, assim: 

        
           * {
                box-sizing: border-box;
                }

Isso simplifica o cálculo de tamanhos e deixa o layout mais previsível.
